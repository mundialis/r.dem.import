DESCRIPTION

r.dsm.import.sn downloads and imports digital surface model (DSM, in German DOM) for Sachsen (SN) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) Landesamt für Geobasisinformation Sachsen (GeoSN) (GeoSN)

EXAMPLE

Sachsen example

Download and import DSM with native resolution: 
r.dsm.import.sn aoi=aoi output=dsm -r
