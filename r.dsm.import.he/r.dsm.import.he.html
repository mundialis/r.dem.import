DESCRIPTION

r.dsm.import.he downloads and imports digital surface model (DSM, in German DOM) for Hessen (HE) and area of interest.
The data can be used when referencing the source:
id: dl-zero-de/2.0,
name: Datenlizenz Deutschland - Zero - Version 2.0,
url: https://www.govdata.de/dl-de/zero-2-0,
source: (c) Hessische Verwaltung für Bodenmanagement und Geoinformation (HVBG)

EXAMPLE

Hessen example

Download and import DSM with native resolution: 
r.dsm.import.he aoi=aoi output=dsm -r
