DESCRIPTION

r.dsm.import.bb downloads and imports digital surface model (DSM, in German DOM) for Brandenburg (BB) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) Landesvermessung und Geobasisinformation Brandenburg (GeoBasis-DE/LGB)

EXAMPLE

Import DSM

Import DSM with native resolution: 
r.dsm.import.bb aoi=aoi_BB output=dsm_BB -r
