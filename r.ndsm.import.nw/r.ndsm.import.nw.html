DESCRIPTION

r.ndsm.import.nw downloads and imports normalized digital surface model (nDSM, in German nDOM) for Nordrhein-Westfalen (NW) and area of interest.
The data can be used when referencing the source:
id: dl-zero-de/2.0,
name: Datenlizenz Deutschland - Zero - Version 2.0,
url: https://www.govdata.de/dl-de/zero-2-0,
source: (c) Landesbetrieb Information und Technik Nordrhein-Westfalen (IT.NRW)

EXAMPLE

Import nDSM

Import nDSMs with native resolution: 
r.ndsm.import.nw aoi=aoi_NW output=ndsm_NW -r
