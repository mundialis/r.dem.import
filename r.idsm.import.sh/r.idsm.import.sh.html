DESCRIPTION

r.idsm.import.sh downloads and imports image based digital surface model (iDSM, in German bDOM) for Schleswig-Holstein (SH) and area of interest.
The data can be used when referencing the source:
id: CC BY 4.0
name: Creative Commons Namensnennung 4.0 International,
url: https://creativecommons.org/licenses/by/4.0/
source: ©GeoBasis-DE/LVermGeo SH (GDI-SH)

EXAMPLE

Import iDSM

Import iDSMs with native resolution: 
r.idsm.import.sh aoi=aoi_sh output=idsm_SH -r
