DESCRIPTION

r.dtm.import.bb downloads and imports digital terrain model (DTM, in German DGM) for Brandenburg (BB) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) Landesvermessung und Geobasisinformation Brandenburg (GeoBasis-DE/LGB)

EXAMPLE

Brandenburg example

Download and import DTM with native resolution: 
r.dtm.import.bb aoi=aoi output=dtm -r
