DESCRIPTION

r.idsm.import.bb downloads and imports image based digital surface model (iDSM, in German bDOM) for Brandenburg (BB) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) Landesvermessung und Geobasisinformation Brandenburg (GeoBasis-DE/LGB)

EXAMPLE

Import iDSM

Import iDSM with native resolution: 
r.idsm.import.bb aoi=aoi_BB output=idsm_BB -r
