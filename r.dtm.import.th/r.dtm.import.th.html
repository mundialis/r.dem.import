DESCRIPTION

r.dtm.import.th downloads and imports digital terrain model (DTM, in German DGM) for Thüringen (TH) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) GDI-Th (GDI-Th)

EXAMPLE

Thüringen example

Download and import DTM with native resolution: 
r.dtm.import.th aoi=aoi output=dtm -r
