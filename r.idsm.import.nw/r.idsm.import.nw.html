DESCRIPTION

r.idsm.import.nw downloads and imports image based digital surface model (iDSM, in German bDOM) for Nordrhein-Westfalen (NW) and area of interest.
The data can be used when referencing the source:
id: dl-zero-de/2.0,
name: Datenlizenz Deutschland - Zero - Version 2.0,
url: https://www.govdata.de/dl-de/zero-2-0,
source: (c) Landesbetrieb Information und Technik Nordrhein-Westfalen (IT.NRW)

EXAMPLE

Import iDSM

Import iDSMs with native resolution: 
r.idsm.import.nw aoi=aoi_NW output=idsm_NW -r
