DESCRIPTION

r.dtm.import.be downloads and imports digital terrain model (DTM, in German DGM) for Berlin (BE) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) FIS-Broker Berlin (FIS-Broker Berlin)

EXAMPLE

Berlin example

Download and import DTM with native resolution: 
r.dtm.import.be aoi=aoi output=dtm -r
