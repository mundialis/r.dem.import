DESCRIPTION

r.dtm.import.sn downloads and imports digital terrain model (DTM, in German DGM) for Sachsen (SN) and area of interest.
The data can be used when referencing the source:
id: dl-by-de/2.0,
name: Datenlizenz Deutschland Namensnennung 2.0,
url: https://www.govdata.de/dl-de/by-2-0,
source: (c) Landesamt für Geobasisinformation Sachsen (GeoSN) (GeoSN)

EXAMPLE

Sachsen example

Download and import DTM with native resolution: 
r.dtm.import.sn aoi=aoi output=dtm -r
