## DESCRIPTION

*r.dtm.import.hb* downloads and imports [digital terrain model (DTM, in
German
DGM)](https://www.metaver.de/trefferanzeige?docuuid=2351ABA6-019D-4155-853F-76EEFC26CA52&q=dgm-bremen)
for Bremen and Bremerhaven (HB) and area of interest.  
The data can be used when referencing the source:  
id: CC-BY 4.0,  
name: Creative Commons Namensnennung 4.0 International,  
url: https://creativecommons.org/licenses/by/4.0/,  
source: (c) Landesamt GeoInformation Bremen ([Geo
Bremen](https://www.geo.bremen.de/))

## EXAMPLE

### Bremen example

Download and import DTM with native resolution:

```sh
r.dtm.import.hb aoi=aoi output=dtm -r
```
